================================================================
        Sara Enterprises — Sales Dashboard
================================================================

A sales analytics dashboard built with Python + Streamlit.
Filter by product, state, city, and gender to explore
sales, profit, and order trends interactively.

----------------------------------------------------------------
  QUICK START
----------------------------------------------------------------

  1. Install dependencies (run once):

       pip install streamlit pandas matplotlib seaborn openpyxl mysql-connector-python

  2. Set up MySQL — create database and tables:

       CREATE DATABASE SalesReport;
       USE SalesReport;

       CREATE TABLE customer (
           CustomerID     INT,
           CustomerName   VARCHAR(100),
           State          VARCHAR(100),
           City           VARCHAR(100),
           Gender         VARCHAR(10),
           OrderDate      DATE
       );

       CREATE TABLE orders (
           OrderID            INT,
           CustomerID         INT,
           Amount             FLOAT,
           Profit             FLOAT,
           Qty                INT,
           ProductCategory    VARCHAR(100),
           ProductSubCategory VARCHAR(100),
           PaymentMode        VARCHAR(50)
       );

  3. Update your MySQL password in:

       preprocessing/Connection.py  -->  password = "your_password"

  4. Load data into the database (run once):

       python load_data.py

  5. Launch the dashboard:

       EASIEST   -->  Double-click  run_app.bat
       TERMINAL  -->  python -m streamlit run app.py

       Opens automatically at http://localhost:8501

----------------------------------------------------------------
  HOW IT WORKS
----------------------------------------------------------------

  RAW DATA
    Ecomm.xlsx has two sheets:
      - CustomerDetail  -->  customer names, city, state, gender
      - Jan             -->  orders, amount, profit, category

  DATA PIPELINE  (Utilities.py)
    load_data()             Reads both sheets from Excel
    data_cleaning()         Drops junk columns, fixes nulls,
                            exports customer.csv + orders.csv
    Data_SaveToDatabase()   Inserts cleaned data into MySQL

  DASHBOARD  (app.py)
    Merges customer + orders on CustomerID
    Filters  -->  Product, State, City, Gender
    KPIs     -->  Total Sales, Total Profit, Qty Sold
    Charts   -->  Profit by Month, Payment Mode, Category
